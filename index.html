🧠 Beyin — Kurulum

1. Token oluştur

  1. github.com/settings/personal-access-tokens adresine git
  2. "Fine-grained tokens" → "Generate new token"
  3. Repository access → Only select repositories → ikinci-beyin
  4. Permissions → Contents → Read and write
  5. "Generate token" → token'ı kopyala (bir daha gösterilmez)

2. Token'ı yapıştır

3. PİN belirle
